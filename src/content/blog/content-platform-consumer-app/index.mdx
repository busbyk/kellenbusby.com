Over the past 3+ years I've been the lead developer for a content platform and consumer app, working closely with the client to architect, build, maintain, and iterate on the product. For the first three years I was the sole developer, building the entire platform from the ground up. As the product has grown, I've expanded the team and now manage other developers alongside continued feature development. The platform serves both a public audience through a content-rich website and a set of creator and partner tools via a separate web application.

## Public Site

- Content-rich website with editorial and user-generated content
- Multiple search experiences with faceted search and filtering
- Data-driven comparison tools
- Data ingestion pipelines from multiple third-party APIs

## Web Application

- Partner and creator dashboard with analytics and reporting
- Customizable branded pages
- Payouts and earnings management
- Personal tracking tools for users

## Backend & Infrastructure

- Headless CMS with custom plugins
- Multi-touch attribution and tracking system
- Transactional email, file storage, and error monitoring

## Tech

- React-based SSR framework
- Headless CMS
- TypeScript
- Node.js

## Infrastructure & Services

- Serverless deployment
- Cloud-based file storage and email services
- Full-text search engine
- Payment processing and connected payouts
- Analytics and error monitoring
